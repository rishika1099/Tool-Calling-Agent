# Demo closet photos

The 56 photos here are **AI-generated** product-style images, one per demo closet piece, made with Google's
`gemini-3.1-flash-image` model on Oct 5 and Oct 7, 2026 from a short description of each garment (for example "a chunky cream
cable-knit wool fisherman sweater"). They are illustrations of the demo data, not photos of real products.
Each file is named after the item's id in `data/demo_wardrobe.json` and is 640 px square.

An earlier version used 21 photos from the CC0 [Clothing dataset](https://github.com/alexeygrigorev/clothing-dataset)
by Alexey Grigorev. Those were replaced so every piece has a photo in one consistent style.
